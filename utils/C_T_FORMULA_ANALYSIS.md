# 谱半径缩放因子 `c_t` 的公式分析

## 问题背景

当前代码中有两个可能的 `c_t` 公式：
1. **ICLR 文档公式**：`c_t = β_t + λ_t`
2. **之前的实现**：`c_t = 1 / (α_t + λ_t)`

需要确定哪个公式更合理。

---

## 一、ICLR 文档的理论依据

### Lemma 中的定义

根据 ICLR 文档的 Lemma，定义：
```
M_t(x) = c_t (H_sym(x) + λ_t I)^{-1}
```
其中 `c_t = β_t + λ_t`，用于确保 `spec(M_t) ⊂ [1/κ_*, 1]`。

### 数学推导

假设：
- `A_t = H_sym + λ_t I`
- `A_t` 的特征值范围：`[λ_min(A_t), λ_max(A_t)]`，其中：
  - `λ_min(A_t) = β_t + λ_t`（最小特征值）
  - `λ_max(A_t) = α_t + λ_t`（最大特征值）
- `A_t` 的条件数：`κ(A_t) = (α_t + λ_t) / (β_t + λ_t) ≤ κ_*`

那么 `A_t^{-1}` 的特征值范围是：`[1/(α_t + λ_t), 1/(β_t + λ_t)]`

如果定义 `M_t = c_t * A_t^{-1}`，其中 `c_t = β_t + λ_t`：

1. **`M_t` 的最小特征值**：
   ```
   λ_min(M_t) = c_t * λ_min(A_t^{-1}) = (β_t + λ_t) * (1/(α_t + λ_t))
              = (β_t + λ_t) / (α_t + λ_t)
              = 1 / κ(A_t)
              ≥ 1/κ_*  （因为 κ(A_t) ≤ κ_*）
   ```

2. **`M_t` 的最大特征值**：
   ```
   λ_max(M_t) = c_t * λ_max(A_t^{-1}) = (β_t + λ_t) * (1/(β_t + λ_t))
              = 1
   ```

因此，`spec(M_t) ⊂ [1/κ_*, 1]` ✅ **符合 Lemma 的保证**

---

## 二、之前的公式 `c_t = 1 / (α_t + λ_t)` 分析

### 数学推导

如果使用 `c_t = 1 / (α_t + λ_t)`：

1. **`M_t` 的最小特征值**：
   ```
   λ_min(M_t) = c_t * λ_min(A_t^{-1}) = (1/(α_t + λ_t)) * (1/(α_t + λ_t))
              = 1 / (α_t + λ_t)^2
   ```
   这个值**通常很小**（因为 `α_t` 通常较大）。

2. **`M_t` 的最大特征值**：
   ```
   λ_max(M_t) = c_t * λ_max(A_t^{-1}) = (1/(α_t + λ_t)) * (1/(β_t + λ_t))
              = 1 / ((α_t + λ_t) * (β_t + λ_t))
   ```
   这个值也**通常很小**。

### 问题

- `spec(M_t)` 的范围**不在** `[1/κ_*, 1]` 内
- 不符合 Lemma 的理论保证
- 可能导致数值不稳定（特征值过小）

---

## 三、实际应用中的差异

### 当前实现方式

我们的代码是这样应用的：
```python
# Step 4: CG 求解得到 d_t = (H + λ_t I)^{-1} * noise_pred
corrected_noise = conjugate_gradient_solve(noise_pred)

# Step 5: 应用 c_t 缩放
corrected_noise = c_t * corrected_noise
```

这等价于：
```
corrected_noise = c_t * (H + λ_t I)^{-1} * noise_pred
                = M_t * noise_pred  （其中 M_t = c_t * (H + λ_t I)^{-1}）
```

### 两种公式的效果对比

**使用 `c_t = β_t + λ_t`**：
- `M_t` 的谱范围：`[1/κ_*, 1]`
- 特征值有理论保证
- 数值稳定

**使用 `c_t = 1 / (α_t + λ_t)`**：
- `M_t` 的谱范围：`[1/(α_t + λ_t)^2, 1/((α_t + λ_t)(β_t + λ_t))]`
- 特征值**可能非常小**（取决于 `α_t` 的大小）
- 可能导致数值不稳定或校正效果过弱

---

## 四、数值稳定性考虑

### 示例计算

假设：
- `α_t = 10.0`（最大特征值）
- `β_t = 0.1`（最小特征值）
- `λ_t = 0.01`（阻尼项）
- `κ_* = 20.0`（目标条件数）

**使用 `c_t = β_t + λ_t = 0.1 + 0.01 = 0.11`**：
- `M_t` 的最小特征值 = `0.11 / (10.0 + 0.01) ≈ 0.011` ≥ `1/20 = 0.05`（如果 `κ(A_t) ≤ 20`）
- `M_t` 的最大特征值 = `0.11 / (0.1 + 0.01) = 1.0`
- **谱范围**：`[0.05, 1.0]` ✅

**使用 `c_t = 1 / (α_t + λ_t) = 1 / 10.01 ≈ 0.0999`**：
- `M_t` 的最小特征值 = `0.0999 / 10.01 ≈ 0.01`
- `M_t` 的最大特征值 = `0.0999 / 0.11 ≈ 0.909`
- **谱范围**：`[0.01, 0.909]` ❌（不在 `[1/κ_*, 1] = [0.05, 1]` 内）

---

## 五、结论和建议

### **推荐使用 `c_t = β_t + λ_t`** ✅

**理由**：
1. **符合 ICLR 文档的理论框架**：直接来自 Lemma 的定义
2. **理论保证**：确保 `spec(M_t) ⊂ [1/κ_*, 1]`
3. **数值稳定性**：特征值在合理范围内（`[1/κ_*, 1]`），不会过小
4. **与条件数控制一致**：`c_t = β_t + λ_t` 与 `κ(A_t) ≤ κ_*` 的条件数控制策略完全一致

### **不推荐使用 `c_t = 1 / (α_t + λ_t)`** ❌

**原因**：
1. **不符合理论框架**：无法保证 `spec(M_t) ⊂ [1/κ_*, 1]`
2. **可能的数值问题**：特征值可能过小，导致校正效果弱
3. **缺乏理论依据**：没有 Lemma 或其他理论支持

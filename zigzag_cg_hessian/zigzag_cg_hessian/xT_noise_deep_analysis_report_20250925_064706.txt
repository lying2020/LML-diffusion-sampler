X_T Gaussian Noise Deep Analysis Report
==================================================

THEORETICAL BACKGROUND:
-------------------------
For pure Gaussian noise X ~ N(0, I):
1. Covariance matrix Cov(X) = I (identity matrix)
2. All eigenvalues should equal 1
3. PC1 and PC2 should have equal variance
4. PC1/PC2 ratio should equal 1.0

WHY PC1 ≠ PC2 IN PRACTICE:
------------------------------
1. FINITE SAMPLE EFFECTS:
   - Limited number of samples causes statistical fluctuations
   - Sample covariance matrix ≠ population covariance matrix
   - Law of large numbers: ratio → 1.0 as n → ∞

2. NUMERICAL PRECISION:
   - Floating point arithmetic introduces small errors
   - SVD algorithm has numerical limitations
   - Machine epsilon effects accumulate

3. RANDOMNESS:
   - Different random seeds produce different results
   - Statistical variability in finite samples
   - Monte Carlo fluctuations

4. ALGORITHM BIAS:
   - PCA/SVD implementation may have small biases
   - Numerical stability considerations
   - Convergence criteria effects

CONCLUSIONS:
------------
1. The deviation from PC1 = PC2 is due to finite sample effects
2. The deviation decreases as sample size increases
3. The deviation is random and follows statistical laws
4. For large enough samples, the ratio approaches 1.0
5. This is a normal statistical phenomenon, not a bug

PRACTICAL IMPLICATIONS:
----------------------
1. For trajectory visualization, small deviations are acceptable
2. For zigzag analysis, consider using larger sample sizes
3. The relative ordering of methods is more important than absolute values
4. Statistical significance tests should account for this variability

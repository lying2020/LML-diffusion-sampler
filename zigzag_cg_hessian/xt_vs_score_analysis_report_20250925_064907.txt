XT vs Score PCA2 Analysis Comparison Report
============================================================

EXPERIMENTAL CONFIGURATION:
------------------------------
Methods: ddim, pndm, dpm, ddpm
Trajectories per method: 20
Inference steps per trajectory: 25

PCA ANALYSIS RESULTS:
-------------------------
XT Analysis:
  - PC1 explained variance: 0.9464
  - PC2 explained variance: 0.0320
  - Total explained variance: 0.9783

Score Analysis:
  - PC1 explained variance: 0.0896
  - PC2 explained variance: 0.0576
  - Total explained variance: 0.1472

ANALYSIS COMPARISON:
--------------------
XT Analysis (Image Space):
  - Represents actual image states during generation
  - Shows trajectory from noise to final image
  - More intuitive for visualization
  - Higher variance explained (image structure)

Score Analysis (Gradient Space):
  - Represents gradient/direction information
  - Shows how the model 'thinks' about generation
  - Better for zigzag analysis
  - May have lower variance explained (gradient noise)

RECOMMENDATIONS:
---------------
1. Use XT analysis for trajectory visualization
2. Use Score analysis for zigzag metrics
3. Combine both for comprehensive understanding
